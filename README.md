# Ergo Jig

*A project for CalSol*

**Goal**: design a jig that make measurements on the driver (so the occupant cell could be better designed)

**Confluence**: https://confluence.calsol.dev/spaces/CG/pages/65733609/Ergo+Jig+Fall+2025 ( short: https://t.ly/eO5XS )

## What happened
**Overview**: 

We started on this project 25 fall and it was a lot of confusion. a lot of ideas was floating around and there is no clear goal nor requirments. Anyways we made some designs and feel free to look in the GitHub commits. It's a really weird process and A LOT happened. 

**Full Story**:

Initially, the plan was to use `3d printed rails + 3030 extrusions`. But than later we did some tests and found out 3D printed rails (we have PTFE tube embedded) aren't good enough, so we settled on `linear rails + 3030`. 

Half way through the designing process we discovered the PVC Pat, the official manikin from WSC. That made us give up on the CalSol manikin and changed all the size. We approximated `20m` of 3030 extrusions and `3m` of linear rails in total. This was built for the 1000 dollars budget that we settled on first semester.

26 spring the leads changed and seems like the hard $1000 budget is gone while when we tried to make it ppl pointed out its too expsensive, and that was already toward the end of the semester. No work was done during the summer.

The most recent idea is to use a combination of wood and 3030 extrusions, and use 3D printed plastic for the joints.
